# Teaching Platform (LMS 1-on-1 Personalized Tutoring)

Hệ thống quản lý học tập (LMS) cá nhân hóa dành cho mô hình gia sư dạy kèm 1-kèm-1, hỗ trợ đa dạng khối lớp và môn học (Toán, Hóa học, Tiếng Anh THPT, Tiểu học).

## 📚 Tài liệu Dự án
- [PROJECT_BRIEF.md](./PROJECT_BRIEF.md): Mục tiêu dự án, cấu trúc buổi học hàng ngày, phân quyền RBAC.
- [database_schema.md](./database_schema.md): Đặc tả kiến trúc CSDL, từ điển dữ liệu, sơ đồ ERD, hợp đồng JSONB và bảo mật RLS.
- [databases.md](./databases.md): Mã nguồn SQL DDL sẵn sàng khởi chạy trên PostgreSQL / Supabase.

## 🚀 Công nghệ dự kiến
- **Frontend:** Next.js / React (triển khai trên Vercel)
- **Database / Auth / Storage:** Supabase (PostgreSQL 15+)
- **Backend:** NestJS / Next.js Server Actions
