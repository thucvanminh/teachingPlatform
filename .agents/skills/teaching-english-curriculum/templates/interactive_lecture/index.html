Ngữ pháp trọng tâm: Mệnh Đề Trạng Ngữ Chỉ Cách Thức & Kết Quả
1. Mệnh đề chỉ cách thức (Manner): S + V + as / just as / like + S + V S + V + as if / as though + S + were / had V3 Diễn tả cách thức hành động diễn ra. Giả định không thật ở HT dùng 'were' cho mọi ngôi.
2. Mệnh đề chỉ kết quả (Result): S + be/V + so + adj/adv + that + S + V S + V + such + (a/an) + adj + N + that + S + V Quá ... đến nỗi mà (So + adj/adv/many/much; Such + cụm danh từ).
3. Chuyên đề Đảo ngữ THPTQG: So + adj + be + S + that... Such + be + (a/an) + adj + N + that... Bẫy chuyển đổi câu kinh điển giữa Too...to, Enough và So/Such...that.
